# Historical demo recorder

This workflow records the former `test-demo` flow, which is no longer defined in
this repository. It needs a current demonstration scenario before it can be used
again. Do not run it as release qualification or publish its old recordings.

The generated casts and GIFs have been removed from the source tree. Recording
scripts and optional dependency installation remain here for a future focused
refresh; they are not part of the release pipeline. Their output path and workflow
selection must be updated together when that refresh is implemented.
