# Dockpipe v0.6.29

Running installed workflows and resolvers preserves their compiled archives.
Content-addressed extraction caches are no longer treated as newer authored
source. Authored source changes and explicit forced builds still recompile.

Boot display dimensions configure an explicit standard VGA device, preserving
the virtual display console. Primary GPU passthrough keeps its existing
configuration. Firmware and guest drivers determine the available modes; the
boot preference does not install a driver or change a running guest's mode.

Healthy Windows Guest Tools repair preserves the running agent, SSH service and
validated configuration. The agent startup task has no execution timeout.

macOS Settings reports native Screen Capture and Accessibility status and offers
explicit access requests and links to System Settings. Status checks do not
prompt. VM display rendering does not require these optional permissions.

QEMU session cleanup retains the primary failure or cancellation status and
bounds termination to the live owned child. Native Windows disk arguments use
extended-length paths so generated runtime directories remain usable by QEMU.
The optional native catalog pins are refreshed independently of the host runtime.

The optional Flatpak catalog uses the selected Platform’s native timeout command
for bounded VM session reporting and retains normal dependency qualification.

Windows QEMU launch failures now propagate the backend exit status through
Dockpipe after preserving its output and best-effort session reporting.

Windows bootstrap USB directories use explicit vvfat options. Ephemeral base
image paths exceeding the tested 259 UTF-8 byte backing-metadata limit now fail
before overlay creation; choose a shorter base path or persistent mode.

Every macOS launcher test target that uses the permissions panel now links the
native permission backend, keeping complete release builds consistent with the app.

Remote brokers retain completed job identities in a private archive when the
recent-job limit is reached. New work can proceed while retries and results
remain addressable by job ID across restarts. Older binaries refuse migrated
state rather than forgetting archived jobs.


Linux desktop packages carry the pinned Qt JPEG runtime and its notices, avoiding
an unavailable libjpeg8 system dependency on Debian. Core archive timestamps and
guest-agent temporary build paths no longer change otherwise identical packages.

Generic VM guest preparation supports automatic and provided-only modes while
media choices remain package-owned. Windows offscreen tests use isolated profiles
and installed system fonts. Canvas presentation refreshes shared theme rules
consistently across repeated view and theme switches. Flatpak CTest uses the same
read-only source input as configure and build.
