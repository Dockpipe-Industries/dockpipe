# Dockpipe v0.6.29

Running installed workflows and resolvers preserves their compiled archives.
Content-addressed extraction caches are no longer treated as newer authored
source. Authored source changes and explicit forced builds still recompile.

Boot display dimensions configure an explicit standard VGA device, preserving
the virtual display console. Primary GPU passthrough keeps its existing
configuration. Firmware and guest drivers determine the available modes; the
boot preference does not install a driver or change a running guest's mode.
