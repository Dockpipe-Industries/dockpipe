# DockPipe v0.6.0

This release focuses on DockPipe installation, package distribution, secrets, and remote execution: you can install into a project, run **workflows** in isolation (Docker by default), and rely on the CLI for day-to-day work. DockPipe **dogfoods itself in CI**—the same binary runs bundled workflows in automation.

---

## Highlights

- **Generated release versions** — each published build advances the numeric patch for the CLI, core, launcher and installers. The permanent staging APT repository supports normal updates for both CLI and desktop.
- **Linux desktop compatibility** — release DEBs build against Ubuntu 22.04 and are installed and tested on both 22.04 and 24.04, covering Pop!_OS 22.04 dependencies.
- **Named secret environments** — explicit variable bindings for 1Password Environments, AWS Secrets Manager, Azure Key Vault, and Infisical; legacy vault templates remain available.
- **Outbound remote nodes** — pair workers without inbound SSH; Cloudflare edge setup is a package resolver behind a provider-neutral contract.

- **DockPipe runs DockPipe** — CI exercises real **`--workflow`** flows against the shipping binary.
- **Architecture is settled** — **workflow** (what happens), **runtime** (where execution runs), **resolver** (which tool or platform), **strategy** (lifecycle wrappers), **assets** (shared support files under **`core/assets/`**).
- **Bundled layout is consistent** — embedded content unpacks to **`bundle/core/`** and **`bundle/workflows/`** (see below).
- **`dockpipe init` is the project entry point** — scaffolds `workflows/`, project configuration, and a starter workflow without copying the core tree.
- **Bundled workflows** — e.g. **`run`**, **`run-apply`**, **`run-apply-validate`**, **`init`**, plus **`bundle/workflows/`** content in the materialized bundle (this repo also runs **`test`**, **`test-demo`**, and optional Codex flows in CI — see **AGENTS.md**).
- **Isolation-first execution** — disposable containers, project at **`/work`**, host bash for prep and follow-up when you need it.
- **Small surface, fast path** — one primitive (run → isolate → act); workflows add structure without turning the core into a heavy orchestrator.

## Bundled layout (materialized)

After the binary unpacks to your cache, the framework tree looks like:

```text
dockpipe/
  core/
    runtimes/
    resolvers/
    strategies/
    assets/
  workflows/
```

Authoring checkouts use `src/core/`, `workflows/`, and `packages/`. Compiled package stores and legacy `templates/` trees are supported.

---

## Usage

```bash
dockpipe init
dockpipe --workflow test --runtime docker
```

You need **Docker** and **bash** on the host. **`dockpipe doctor`** checks the toolchain and bundled assets.

## Installation

Linux (or use the signed APT instructions in [docs/install.md](https://github.com/Dockpipe-Industries/dockpipe/blob/v0.6.0/docs/install.md)):

```bash
curl -fsSL https://github.com/Dockpipe-Industries/dockpipe/releases/download/v0.6.0/install.sh -o /tmp/dockpipe-install.sh
DOCKPIPE_VERSION=0.6.0 sh /tmp/dockpipe-install.sh
```

macOS, including Apple Silicon:

```bash
curl -fsSL https://github.com/Dockpipe-Industries/dockpipe/releases/download/v0.6.0/install.sh -o /tmp/dockpipe-install.sh
DOCKPIPE_VERSION=0.6.0 sh /tmp/dockpipe-install.sh
export PATH="$HOME/.local/bin:$PATH"
```

Windows PowerShell (native CLI; WSL is optional):

```powershell
Invoke-WebRequest https://github.com/Dockpipe-Industries/dockpipe/releases/download/v0.6.0/install.ps1 -OutFile install.ps1
.\install.ps1 -Version 0.6.0 -SkipWSLSetup
```

Portable archives and complete native package-store bundles are available in the release assets. Verify downloads against `SHA256SUMS.txt`. Container workflows additionally require Docker. Host workflows use Bash and their resolver's tools. PipeLang's broader language rollout is deferred; this release focuses on the DockPipe runtime and packages.

## Notes

- **Native distribution** — Linux DEB/RPM/APK/Arch packages, macOS Intel/Apple Silicon tarballs, Windows ZIP/MSI, and matching complete package stores.
- **Signed APT and direct downloads** — packages.dockpipe.com serves the repository and versioned downloads after production provisioning and publication. Install scripts require checksums.
- **Pre-1.0** — flags, env names, and YAML fields may still adjust slightly between releases; pin versions in production if you need stability.
