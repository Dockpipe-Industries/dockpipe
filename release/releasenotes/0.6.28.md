# Dockpipe v0.6.28

This candidate adds a generic macOS backend to the existing QEMU VM runtime.
It emulates x86_64 with TCG on Intel and Apple Silicon, preserves the shared disk,
firmware, TPM, media and SSH lifecycle, and owns QEMU in the foreground. HVF and
host PCI passthrough are not supported by this backend.

The optional VM toolchain requires Bash 4.3 or newer. Set an absolute
`DOCKPIPE_HOST_BASH_BIN` to select an installed interpreter for Bash host scripts
and sourced pre-scripts. Invalid explicit selections fail without falling back.
The desktop's native host-shell defaults remain unchanged. Bounded VM session
reporting requires GNU `timeout` or `gtimeout`; neither dependency is installed
implicitly. See [Darwin VM runtime](../../docs/runtime/vm-darwin.md).

The VM application workflows, QEMU resolver, native display factory and Guest
Tools remain separately versioned optional packages. The new package cohort must
consume an actual published backend-capable CLI candidate meeting the 0.6.28-0
minimum. If intervening releases advance the generated candidate version, its
actual source identity and literal version must be bound rather than relabelled. Local unit tests and cross-builds
do not establish native macOS guest qualification, Windows installation, guest
driver support or additional native package platforms. Those acceptance gates
remain required before promoting the corresponding package candidate.
