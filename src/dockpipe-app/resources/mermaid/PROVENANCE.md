## Chromium 90 compatibility

Qt 6.2's Chromium 90 cannot parse the upstream bundle's class static initialization
blocks. Its standard library also lacks APIs used by Mermaid. The checked-in
`mermaid.min.js` therefore contains syntax lowered to `chrome90` by esbuild 0.25.12,
with template literals lowered to preserve their values using escaped newlines,
preceded by only these core-js 3.45.1 standard polyfill entries:

- `actual/object/has-own`
- `actual/object/group-by`
- `actual/array/at`
- `actual/string/at`
- `actual/structured-clone`

Core-js is MIT licensed (`LICENSE.core-js`); its full notice is also embedded in the
runtime. Polyfills run only inside the isolated offline Mermaid page. They preserve
native implementations where supported. The upstream diagram code and version are
unchanged; this build changes supported syntax and supplies standard APIs.

Build dependencies and registry integrity hashes are pinned in `vendor-build/package-lock.json`.
The dependencies are build tools only; the application does not install or download
Node packages. The generated asset has no source map or private build paths.

## Rebuild

Use Node 18 or newer and a temporary build directory. Obtain the exact archive
above, verify its registry integrity, and extract only its standalone distribution.
From this directory, with the archive saved as `/tmp/mermaid-12.2.0.tgz`:

```sh
build_dir="$(mktemp -d /tmp/dockpipe-mermaid-build.XXXXXX)"
cp vendor-build/package.json vendor-build/package-lock.json "$build_dir/"
npm ci --prefix "$build_dir" --ignore-scripts --no-audit --no-fund
tar -xOzf /tmp/mermaid-12.2.0.tgz package/dist/mermaid.min.js > "$build_dir/upstream.js"
node vendor-build/rebuild-runtime.mjs "$build_dir/upstream.js" "$build_dir" mermaid.min.js
```

The script verifies exact dependency versions and the upstream SHA-256 before
building. It enforces a 6 MiB upstream input and 8 MiB generated output bound and
prints the generated byte count and SHA-256. Repeated builds produce identical bytes.

The offline renderer does not download scripts, fonts, images or diagram resources.
CSP, the exact resource allowlist, strict Mermaid settings, source/edge limits,
render timeout, and decoded image limits remain enforced by the existing renderer.
