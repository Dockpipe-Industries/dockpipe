## Emitter correction and compatibility

`gobackend/generate.go` now selects function-level ordered statements by Core local
structure, independently of language version and conditional count. Selection follows
specialized propagation handling so early Optional/Result failure returns keep their
existing semantics. At expression positions, a sequence uses one lexical block closure;
match arms, conditional branches, call composition and propagation continuations enter
this same path. Initializers still evaluate once in order, including unused bindings;
the scope advances only after initialization. Terminal branches remain lazy and scoped.

The recursive continuation-per-local pattern remains only for a single binding, whose
continuation is not another local. Nested expression scopes may contain closures, but
sequential local count no longer creates one enclosing closure per binding. Existing
checked/cross-payload propagation chain emitters already iterate their stages.

Generated bytes intentionally change for adjacent local sequences, including previously
admitted contracts, and for some v0.84 multi-choice bodies formerly selected by the
version gate. Single-local and unrelated outputs retain their spelling. No golden was
refreshed, source/Core admission or evaluator changed, or new language version introduced.
This supersedes the earlier v0.84 record's blanket historical-byte preservation claim.

## Containment and verification status

deadline before launching workloads. Every generated child in both PipeLang helpers and
all six Application IR entry points rechecks these controls, uses a 30-second deadline,
and terminates the entire unit on memory pressure, timeout or accounting failure.
Generated Go tests use `-count=1 -p=1 -timeout=25s`. Unsupported hosts fail closed; no
uncontained strategy is silently substituted.

Synthetic timeout cancellation killed a child that created a new session. Proactive
memory cancellation stopped around 801 MiB with zero OOM/swap events. An independent
one-second service deadline also removed its complete child tree without a monitor.

after 271.9 seconds, with no OOM or swap. It did not complete verification. Fresh top-level batches then isolated a large v0.83 all-scope-pair fixture: at the stop,
its compiler used about 567 MiB RSS and the unit held about 180 MiB of file charges.
The test now compiles at most 24 sample methods plus their two helpers per generated
module. It retains all source/HIR/Core/full-program determinism checks, evaluator
outcomes and executable ordered traces. Limits and normal inlining remain unchanged.

The batched root suite discovered 495 top-level tests. Its two incomplete tests were
the new matrix's corrected fixture scope and the large v0.83 test; the other 493 have
passed. The matrix subsequently passed in full. A combined corrected-matrix/large-fixture run
reached its last shape and again hit accumulated aggregate charges, so final v0.83

All five durable containment integration probes pass after correcting the host's
