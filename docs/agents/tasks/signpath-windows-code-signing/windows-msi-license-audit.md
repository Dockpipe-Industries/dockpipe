# Windows MSI license audit

The published [Dockpipe v0.6.11 Windows x64 MSI](https://github.com/Dockpipe-Industries/dockpipe/releases/tag/v0.6.11) matches GitHub's SHA-256 digest `6da0781e6b9b6e7da3b92b819717a2964d4acb218a877194cec0fd16fe81c44d`. The MSI File table and extracted payload both contain 69 files. The embedded core archive contains 67 entries, including one Windows executable. The MSI Binary table also contains one WiX custom-action binary and six WiX UI resources. Inspection did not execute the installer or its payload.

| Component | Evidence and disposition |
| --- | --- |
| Dockpipe CLI, launcher, core archive and guest agent | Dockpipe's project license is Apache-2.0 and the MSI includes its license text. Limit SignPath signing requests to Dockpipe-built executable files and the enclosing MSI. |
| Go toolchain and CLI dependencies | Build metadata identifies Go 1.26.9, go-shellwords v1.0.12 (MIT), jsonschema v5.3.1 (Apache-2.0), x/sys v0.47.0 and x/term v0.27.0 (BSD-3-Clause), and yaml.v3 v3.0.1 (Apache-2.0 and MIT). The embedded guest agent reports no external Go modules. The installed license folder lacks a consolidated notice for the Go runtime and dependencies. Package their applicable licenses and notices. |
| Qt DLLs, plugins and translations | The Qt Core DLL reports 6.8.3. The loader uses shared DLLs. The MSI carries the LGPLv3 and GPLv3 texts, compatible-library replacement instructions and the corresponding Qt source link. Verify module-level and bundled third-party notices against the shipped build. [Qt licensing](https://doc.qt.io/qt-6/licensing.html) |
| Mesa software OpenGL and DirectX Shader Compiler | Qt documents `opengl32sw.dll` as its Mesa llvmpipe fallback. Mesa is primarily MIT-licensed with component notices. The included `dxcompiler.dll` reports 1.8.2502.11. Microsoft publishes the compiler under the University of Illinois Open Source License. Verify exact binary provenance and add the applicable upstream notices, or exclude unused fallback components after a Windows compatibility check. [Qt graphics](https://doc.qt.io/qt-6.8/windows-graphics.html) · [Mesa licensing](https://docs.mesa3d.org/license.html) · [DirectX Shader Compiler](https://github.com/microsoft/DirectXShaderCompiler) |
| Microsoft Visual C++ and DirectX redistributables | The MSI contains 10 Visual C++ runtime DLLs, `vc_redist.x64.exe`, `d3dcompiler_47.dll` and `dxil.dll` 1.8.2502.11. The CustomAction table contains only WiX's EULA print action. Microsoft applies separate redistribution terms to its runtime and DXIL signing validator. Check the original redistribution source, applicable REDIST list and notices. Ask SignPath whether these files qualify as System Libraries before requesting signing for the MSI. If needed, qualify an installer that consumes the official prerequisite separately. [Microsoft redistribution guidance](https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files) · [Microsoft DXC package license split](https://www.nuget.org/packages/Microsoft.Direct3D.DXC/1.8.2405.17) · [SignPath terms](https://signpath.org/terms) |
| WiX installer UI | The MSI embeds `WixUIWixca` for EULA printing and six UI assets. The release script pins WiX 3.14.1 and its source is under MS-RL. Include the applicable source and license materials for the embedded files and confirm the artifact treatment with SignPath. [WiX 3.14.1 license](https://github.com/wixtoolset/wix3/blob/wix3141rtm/LICENSE.TXT) |

The audit covers the published MSI. The current release workflow's pinned Browser SDK and the proposed administrator-input service require separate review against their actual Windows payloads. The Browser SDK's exact public source and license could not be verified from the pinned GitHub endpoint. The proposed service has no published installer.
