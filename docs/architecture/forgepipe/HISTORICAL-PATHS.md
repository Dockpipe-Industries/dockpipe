# Historical repository paths

The inventories, extraction proposals and proof snapshots in this directory record
paths from the earlier Dockpipe monorepo. Their `packages/` and language-source
paths are historical evidence, not instructions to recreate those trees here.

Current package source and examples are in
[dockpipe-packages](https://github.com/Dockpipe-Industries/dockpipe-packages/tree/master/packages).
Compiler, application IR, language tests and SDK documentation are in
[PipeLang](https://github.com/Dockpipe-Industries/pipelang).
[Current ownership](../../packages/core-tools.md) governs new work. Read artifact
pins and acceptance claims at their recorded revision; moving source does not
requalify historical artifacts or publish a new release.
