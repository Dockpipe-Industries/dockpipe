# Historical QEMU Gate 1 evidence

These three JSON files preserve the exact manifest, build contract, and build
specification from the 2026-08-07 machine-specific qualification build. Absolute
paths, hashes, and ownership describe that historical run; they are not portable
configuration or current defaults. The files were moved here without changing
their bytes. The original recipe remains recoverable through Git history.

Current package recipes live in `packages/vm/toolchains/qemu-11.0.3-linux-amd64/`.
They require explicit paths and produce new build records and hashes. This
historical evidence does not qualify the parameterized recipe or a new bundle.
