# Company artwork

`dockpipe-industries.png` is the unmodified company logo referenced by
`CompanyLogo.qml` on [Dockpipe's company page](https://dockpipe.com/#company).
The website embeds it as `qrc:/images/dockpipe-industries.png`; this copy comes
from that website source asset, not from a screenshot or a recreated logo.

Imported 2026-10-15. SHA-256:
`89f53d70c368279fb3c2066f4d2bfe74efcf0440eaece79454e8eb223d976bc6`.

The original is bundled in the optional Cockpit package. HQ uses a 320-pixel
texture through the existing display pipeline, with no runtime network fetch.
The charcoal and mint reception palette follows the company's `ConsoleTheme`.
This is first-party branding, not a third-party asset library.
